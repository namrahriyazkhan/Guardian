❓ Security Glossary
✕
Kill Chain
A framework detailing phases of a cyberattack: Reconnaissance, Weaponization, Delivery, Exploitation, Installation, C2, and Actions on Objectives.
MITRE ATT&CK
Globally accessible knowledge base of adversary tactics, techniques, and procedures based on real-world observations.
Alert Fatigue
The state where analysts become desensitized to frequent security alerts, potentially missing critical security incidents.
Command & Control (C2)
Communication channel established between compromised system and attacker server to receive instructions and exfiltrate data.
Process Injection
Method of executing malicious code within the address space of a legitimate running process to evade detection.
